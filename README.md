# Library Management System

A Python and SQLite based Library Management System for managing books and library records.

## Features

* Add Book
* View Books
* Issue Book
* Return Book
* Delete Book

## Technologies Used

* Python
* SQLite

## How to Run

1. Install Python
2. Download the project files
3. Open terminal in the project folder
4. Run:

```bash
python library_management.py
```

## Project Description

This project is designed to manage library operations efficiently. It allows users to add, view, issue, return, and delete books using a simple command-line interface. SQLite is used as the database to store and manage book records.
